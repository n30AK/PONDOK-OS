## 4. Integrasi pendidikan Diknas dan Kemenag

Gunakan model data pendidikan internal terpadu, tetapi adapter eksternal terpisah.

1. Identitas satuan pendidikan internal menyimpan jalur, kementerian pembina, jenjang, status, nomor identitas resmi, lokasi, izin dan masa berlaku.
2. Seorang santri dapat mempunyai beberapa enrolment (misalnya diniyah dan sekolah formal); kalender, rombel, nilai, status dan pelaporan tiap satuan tetap dibedakan.
3. Modul Sekolah/Diknas menangani PPDB, peserta didik, PTK, rombel, jadwal, kurikulum, asesmen, rapor, kelulusan, sarpras, pembiayaan, mutu dan akreditasi.
4. Modul Madrasah/Pesantren Kemenag mengikuti rezim pelaporan satuan terkait. Jangan mencampur identitas pelaporan Diknas dan Kemenag.
5. Dapodik, EMIS, Verval dan layanan pemerintah lain tidak diasumsikan mempunyai API publik. Adapter hanya boleh aktif setelah dokumentasi/API resmi, izin akses, autentikasi dan ketentuan pemrosesan diverifikasi. Dilarang scraping atau menyimpan kredensial operator secara tidak aman.
6. Sinkronisasi wajib punya preview/dry-run, pemetaan kode, idempotency, log per baris, laporan konflik, persetujuan operator dan rekonsiliasi. Jangan menimpa data pemerintah otomatis.
